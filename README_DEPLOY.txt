MYCNC3D V2.1 — PRODUCTION BUILD
================================

This package is intended to replace the current GitHub Pages site.

Included:
- EN/FR homepage
- 12 bilingual R&D project pages
- 6 dedicated validated R&D visuals
- R&D maturity/status legend
- legal pages EN/FR
- responsive mobile navigation
- custom 404 page
- canonical + hreflang + Open Graph + Twitter image metadata
- Organization structured data
- sitemap.xml + robots.txt
- favicon, Apple touch icon and web app manifest
- CNAME for mycnc3d.com
- optimized WebP project imagery
- dedicated 1200×630 social-sharing images

Deployment
----------
1. Back up the current GitHub repository.
2. Replace the repository root contents with the contents of this ZIP.
3. Keep the CNAME file unchanged.
4. Commit to main.
5. Wait for GitHub Pages deployment.
6. Hard-refresh https://mycnc3d.com.
7. Test EN/FR, project pages, mobile navigation, mail links and legal pages.

Suggested commit message:
Publish MYCNC3D V2.1 production site
